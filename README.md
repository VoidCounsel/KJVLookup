**Fast KJV Bible Phrase Finder**  
A lightweight, terminal-based tool for instant English phrase searches in the King James Version Bible.

**Key Features**  
- Downloads the full KJV text (~4 MB plain-text file) once from a public source  
- Loads all 31,102 verses into memory for lightning-fast searches  
- Case-insensitive matching — finds single letters (“a”, “q”), short words, or full phrases  
- Shows every matching verse with:  
  - Clear book/chapter:verse reference  
  - Highlighted match in yellow  
  - ~20 words of context before and after for better understanding  
- Clean ANSI-colored terminal output  
- Simple interactive loop: just type your search term and press Enter  
- No API keys, no rate limits, fully offline after first download  

**Usage**  
Run the script → enter any phrase → view results instantly.  
Press Ctrl+C to exit.

Perfect for quick word studies, phrase lookups, or curiosity-driven Bible exploration.
